PREVIEW: Open index.html in a browser. The website is static HTML/CSS/JS.

FREE HOSTING (GITHUB PAGES):
1. Create a GitHub account if needed.
2. Create a new PUBLIC repository named christopher-portfolio.
3. Upload index.html, style.css, and script.js to the repository root.
4. In repository Settings > Pages, choose Deploy from a branch, main, /(root), and Save.
5. Wait for GitHub to display the live URL, then test it on a phone and in a private browser window.
